# Machine Learning Coursework
Coursework portfolio for **ITAI-1371 – Machine Learning at Houston Community College**, featuring hands-on labs, a Titanic classification midterm, and an NLP sentiment-analysis final project.
## Repository Structure
### Labs
Hands-on machine learning exercises covering:
- Exploratory data analysis
- Data preparation
- Regression and classification
- Model evaluation
- Bias-variance tradeoff
- Ensemble methods
- Unsupervised learning
- Hyperparameter tuning and AutoML
- Ethics, fairness, and bias
- Machine learning pipelines

### Assignments
#### Titanic Machine Learning Midterm
Explored Titanic passenger survival and compared Logistic Regression with Random Forest classification.

Best test accuracy: **81.56%**

[View Midterm Project](Assignments/Midterm-Project)

#### Amazon Review Sentiment Analysis
Built an NLP workflow using TF-IDF, Logistic Regression, and Multinomial Naive Bayes to classify Amazon product reviews.

Best test accuracy: **79.8%**
