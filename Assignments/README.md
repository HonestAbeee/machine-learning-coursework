# Machine Learning Assignments
Assignments and projects completed for **ITAI-1371 – Machine Learning at Houston Community College**.
## Midterm Project
### Titanic Machine Learning Midterm
Used the Titanic dataset to explore passenger survival and compare classification models.
Highlights:
- Exploratory data analysis
- Data preprocessing and feature encoding
- Logistic Regression
- Random Forest
- Confusion matrix and classification report evaluation
- Best test accuracy: **81.56%**

## Final Project
### Amazon Review Sentiment Analysis
Built a natural language processing workflow to classify Amazon reviews as positive or negative.
Highlights:
- Text cleaning and preprocessing
- TF-IDF feature extraction
- Logistic Regression
- Multinomial Naive Bayes
- Error analysis and business interpretation
- Best test accuracy: **79.8%**
