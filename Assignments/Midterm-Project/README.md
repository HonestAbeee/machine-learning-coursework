# Titanic Machine Learning Midterm
Midterm project for **ITAI-1371 at Houston Community College** using the Titanic dataset to explore passenger survival and build classification models.

## Project Overview
The project includes:
- Exploratory data analysis
- Missing-value handling
- Categorical feature encoding
- Feature selection
- Train/test splitting
- Logistic Regression
- Random Forest classification
- Confusion matrix and classification report evaluation

## Results
| Model | Test Accuracy |
|---|---:|
| Logistic Regression | **80.45%** |
| Random Forest | **81.56%** |

Random Forest produced the highest test accuracy.
